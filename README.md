# Calculator-Minigame
---
### Calculator minigame made using python that currently is done with creating/accessing a text file containing all of the Scorers Name and Score achieved by the Scorer that is all locally stored in the users device.
---
Libraries used are (*Random, Time, Os*)
  - **Both Time and Os libraries are only used to prevent Overflow errors and to enchance the visual look of the code during execution no harm is to be performed through this program. The only file interacted in the execution of this program is the txt file by the program (History Saved Scores.txt)**

Planned upgrades to be implemented in the future versions
- Global leaderboard
- Correct answer streak multiplier based off of continous hard difficulty selection
